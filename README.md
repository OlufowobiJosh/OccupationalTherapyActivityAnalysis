# Occupational Therapy Activity Analysis

**Healthcare operational analytics | Interactive dashboard | Synthetic data**

[Open the interactive dashboard](https://olufowobijosh.github.io/OccupationalTherapyActivityAnalysis/)

## Business problem
Hospital managers need visibility into the uptake of occupational therapy sessions: which activities patients accept or decline, engagement over time, and attended minutes. Better reporting can help staff review activity planning and identify questions for follow-up.

## Workplace project vs public recreation
The original analysis was performed using **Excel** and confidential workplace activity records. The public portfolio version is an **interactive HTML/JavaScript recreation** using 180 completely synthetic records. It is not the original Excel workbook, and its counts, charts and insights do not represent workplace findings.

## Analysis
- Sessions offered, accepted, declined, cancelled and not recorded
- Acceptance and decline rates
- Activity-level participation
- Monthly engagement trends
- Morning, afternoon and evening comparisons
- Total and average attended minutes

## Interactive dashboard
Open `index.html` in a browser. Use the **Month**, **Activity type**, **Time of day**, and **Session outcome** dropdowns. KPI cards, charts and operational insights update instantly.

## Files
- `index.html`: self-contained interactive dashboard, no installation needed
- `synthetic_occupational_therapy.csv`: fabricated activity records
- `REPORT.md`: business problem, approach and analytical interpretation

## Data privacy
**All public data are synthetic. The uploaded dashboard and figures differ from the actual confidential workplace analysis. No patient-identifiable information, real records, or original workplace screenshots are included.**
